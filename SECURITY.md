# Security policy

Please do not report vulnerabilities, exposed credentials, authentication bypasses, or private user data in public issues.

Send a private report through the security contact published at [developers.aldiwan.net](https://developers.aldiwan.net). Include the affected repository, reproducible steps, impact, and a safe proof of concept. Do not access data that is not yours and do not disrupt production traffic.

We will acknowledge a valid report as soon as practical and coordinate disclosure after a fix is available.
