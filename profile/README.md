# الديوان للمطورين

نبني البنية المفتوحة التي تساعد المطورين على استكشاف الشعر العربي وتقديمه بتجارب رقمية جميلة وآمنة.

We build open developer tools for exploring and presenting Arabic poetry with correct typography, explicit API contracts, and production-minded examples.

## Start building

| Project | Purpose |
| --- | --- |
