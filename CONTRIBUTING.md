# Contributing · المساهمة

Thank you for helping improve Arabic developer tooling.

1. Open an issue before a large behavioral change.
2. Fork the repository and create a focused branch.
3. Add or update tests and documentation.
4. Run the repository's formatter, analyzer, and test suite.
5. Never commit API keys, tokens, production payloads, or personal data.
6. Submit a small, clearly described pull request.

Arabic and English contributions are both welcome. Public APIs follow semantic versioning; breaking changes require a new major version and a migration note.
