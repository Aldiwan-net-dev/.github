# AlDiwan Open Source · الديوان مفتوح المصدر

Shared community standards and security defaults for the public repositories maintained by [AlDiwan](https://www.aldiwan.net).

يضم هذا المستودع السياسات والقوالب المشتركة لمشروعات الديوان مفتوحة المصدر، بهدف بناء أدوات عربية موثوقة وممتعة لمجتمع المطورين.
